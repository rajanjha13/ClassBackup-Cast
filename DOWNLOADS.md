# ClassBackup Cast downloads

[Download Windows receiver 0.9.1](https://github.com/rajanjha13/ClassBackup-Cast/releases/download/v0.9.1/ClassBackup-Cast-Setup.exe)

[Download Android sender 0.8.3](https://github.com/rajanjha13/ClassBackup-Cast/releases/download/v0.9.1/ClassBackup-Cast-Sender.apk)

[Release notes, source archive and checksums](https://github.com/rajanjha13/ClassBackup-Cast/releases/tag/v0.9.1)

Install the receiver on your Windows x64 PC. Android tablets need the sender APK; iPad uses Control Center → Screen Mirroring. Use the same trusted local network. One sender at a time. Android shares video only and its video is unencrypted.

Receiver activation costs INR 1,000 once. Contact [ClassBackup](https://classbackupapp.in/) for purchase and activation instructions. Activation is stored for the current Windows account on that PC. No activation password is published here.

This is a release candidate: the Windows installer is unsigned, the Android APK is development-signed, and broad Android/OBS lesson-length testing remains pending. Store listings are not yet published.

For OBS Studio, add a Window Capture source for ClassBackup Cast - Output and your microphone separately. Test before class.

Corresponding source, build scripts and third-party licence notices (including modified GPL-3.0-or-later UxPlay) are provided in the source ZIP attached to the release.
